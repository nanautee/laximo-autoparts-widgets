Виджеты подбора автозапчастей
Laximo + ABCP

Три встраиваемых виджета: поиск по VIN, каталог по автомобилю и поиск по OEM-номеру с кросс-номерами. Backend на Spring Boot скрывает ключи Laximo и ABCP, нормализует ответы под интерфейс и кэширует их в Redis, чтобы не платить за каждый повторный запрос.

Backend-прокси вместо прямых вызовов

Виджеты ходят только в наш API. Он прячет учётные данные Laximo и ABCP, приводит SOAP-ответы к плоским DTO и добавляет кэш. Ключи не покидают сервер, а интеграция с ABCP переключается одной переменной окружения — без правок во фронтенде.

Redis с TTL по волатильности данных

Laximo тарифицирует каждый SOAP-вызов, поэтому сроки жизни кэша заданы осознанно: VIN — 72 часа, справочники марок — 30 дней, дерево каталога — 7 дней, кросс-номера — 6 часов. Ключи хэшируются, попадание видно в ответе.

Передача в корзину ABCP

«В корзину» собирает позиции с OEM-номером, backend формирует тело запроса ABCP и отправляет его в тестовую среду. Ответ возвращает точный JSON запроса — контракт интеграции можно сверить с документацией заказчика без чтения кода.

Ленивое дерево каталога

Полное дерево деталей одного автомобиля — тысячи узлов, поэтому виджет подгружает уровень за уровнем. Отдача от первого байта до карточки детали остаётся быстрой, а уже загруженные уровни не перезапрашиваются.
